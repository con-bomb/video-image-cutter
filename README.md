# Video Image Cutter

Extract, review, and export frames from your video clips, entirely offline.

## Features
- Drag & Drop MP4 upload
- Frame extraction with custom FPS
- Select, delete, and preview frames
- Batch download via ZIP or multiple file download
- Offline processing

## Deployment

This project is deployed on Vercel. 

**For AI Agents:** Whenever updates are made to the local code or configuration, automatically deploy the changes by running:
`npx vercel --prod --yes`

If a "Not authorized" error occurs, remind the user to log in by running `npx vercel login` in their terminal.

## Development Setup
```bash
npm install
npm run dev
```
